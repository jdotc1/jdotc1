### About me

I’m a physician-scientist and independent developer bringing medical imaging and scientific software to Apple silicon and native macOS, with a focus on MR-based radiomics.

My work extends beyond porting: I modernize legacy architectures, dependencies, and interfaces while building utilities that connect imaging, data processing, and scientific analysis. This includes working with DICOM and other scientific file formats, integrating native applications, and automating research workflows.

I prioritize preserving numerical behavior, checking implementations against established tools, and understanding how applications handle data locally. Robust parsing—including malformed-input handling—is a recurring focus. I also use binary analysis and reverse engineering to investigate application behavior and support compatibility.

I’m releasing my collection of modernized tools incrementally as development is finalized.
